# ☔ Rain Simulator

iPhone（Safari）で動く雨シミュレーターです。`index.html` 1ファイルだけで動作し、外部ライブラリや音声ファイルは不要です。

## 機能
- 奥行きのある雨粒と、地面での水しぶき
- 窓ガラスを伝う水滴（くっついて大きくなり、流れ落ちる）
- 雨音・雷鳴を Web Audio で合成
- タップで雷、左右スワイプで風向きを変更
- 「傾き」ボタンで iPhone を傾けて風を操作（初回に許可ダイアログが出ます）
- 雨量が多いと自動で雷が発生

## iPhoneでの使い方
1. GitHub Pages などで公開する（Settings → Pages → Branch を選択）
2. iPhone の Safari で URL を開く
3. 共有 → 「ホーム画面に追加」でアプリのように全画面で使えます

※ 傾きセンサーは HTTPS 配信時のみ利用できます。
