# ☔ Rain Simulator

iPhone（Safari）で動く、物理モデルにもとづいた雨シミュレーターです。`index.html` 1ファイルだけで動き、外部ライブラリも音声ファイルも使っていません。映像も音も、すべてその場で計算して作っています。

## 操作
- **タップ**：落雷（距離と、雷鳴が届くまでの秒数を表示）
- **左右スワイプ**：風速を変更
- **設定**：雨量（mm/h）・風速（m/s）・音量／窓ガラス・傾き・雷・スリープタイマー
- **傾き**：加速度センサーで本当の重力方向を使います。雨は現実の「下」へ降り、窓の水滴も重力方向へ流れます（机に平らに置くと水滴は止まります）
- **タイマー**：15／30／60分。最後の90秒で音がデシベル単位で一定の割合で小さくなり（自然なフェードアウト）、止まります

## 物理・流体力学
| 現象 | モデル |
|---|---|
| 雨滴の大きさ | Marshall–Palmer 分布 N(D)=N₀e^(−ΛD), Λ=4.1R^−0.21 |
| 落下速度 | 終端速度 v(D)=9.65−10.3e^(−0.6D) m/s（Atlas ほか, 1973） |
| 風 | 抗力による緩和（時定数 τ=v/g）。突風は風に流される乱流場（Taylor の凍結乱流仮説）として扱い、突風の前線が画面を横切る |
| 雨量のゆらぎ | 1/f ゆらぎで時間変化し、濃淡のある「雨の幕」が流れていく |
| 地面への衝突 | Cossali の条件 K=We·Oh^−0.4 > 2100+5880δ^1.44 を満たすときだけ王冠状のしぶきが上がる |
| 波紋 | 表面張力波と重力波が混ざった波束。群速度で広がり、粘性で減衰する。水たまりの中だけにできる |
| 窓の水滴（動き出し） | Furmidge の力の釣り合い：重力＋風の抗力 ＞ 接触線のピン止め力 2aσΔ になると流れ出す |
| 窓の水滴（流れ方） | 接触線の粘性散逸（Ca=μU/σ）で速度が決まる。先端が丸く尾が細い涙形になり、濡れた跡をたどり、小さな粒を残し、体積を保存して合体する |
| 雨だれ | Tate の法則（Harkins–Brown 補正）で滴下量が決まる。蛇口のしずくのように、流量が増えると一定のリズム → 長短交互（周期倍分岐）→ 不規則（カオス）へ変わる |
| 雷 | 3次元の曲がりくねった放電路（枝分かれ・雲内部分を含む）を生成し、映像と雷鳴に同じ形を使う。約6割は雲の中だけの放電 |

## 光学
| 現象 | モデル |
|---|---|
| 雨筋の明るさ | 露光時間中に雨滴が1画素を横切る時間の割合（Garg & Nayar）× 照明 |
| 街灯・ヘッドライト | 距離の2乗で弱まり、Henyey–Greenstein 位相関数で前方に強く散乱する。光源の手前の雨が光る。ヘッドライトは光線の円錐内だけを照らす |
| ピント | 被写界深度（錯乱円）。窓ガラスにピントを合わせると、外の景色と雨がボケる |
| 窓の水滴 | 球レンズとして背景を上下反転して映す。縁は全反射で暗く、下側は集光で明るい |
| 雷光 | 雲の中から雲底が照らされ、建物はシルエットになり、水たまりに映る。放電は1ミリ秒未満なので、その光の中で雨粒が止まって見える |
| 夜の窓 | ガラスは片面で約4%反射する（Fresnel）。部屋の明かりがぼんやり映り込む |
| 視程 | 雨量が多いほど景色がかすみ、路面の上に細かいしぶきの霧が漂う |

## 音響
| 音 | モデル |
|---|---|
| 雨音 | 路面・水たまりへの何千もの衝突を1つずつ合成。距離は面積に比例して分布させ、振幅は D^1.5/r、遠い音ほど空気吸収で高音が落ちる。1mm前後の雨粒は約14kHz、大きい雨粒は2〜6kHzで鳴る Minnaert 泡共鳴を含む |
| 繰り返し感をなくす | ループ再生ではなく、ランダムな位置から取り出した断片を等パワーのクロスフェードでつなぐ（同じ音が二度と繰り返されない） |
| 窓ガラス越し | 質量則による透過損失（オクターブごとに6dB減衰）と、コインシデンス周波数（約2.4kHz）付近での透過の増加 |
| 残響 | 向かいの建物（14m）と地面からの初期反射＋RT60 1.3秒の街路残響 |
| 雷鳴 | 放電路4mごとに N 波を発生させる。到達時間 r/c、振幅 ∝ ΔL/r、放電路に垂直な方向ほど強い。遠くほど N 波が伸び、空気吸収で低音だけが残る |
| 風 | 音響パワーが風速の6乗に比例（Curle）。電線と窓枠にはストローハル数による風切り音（f=0.2U/d） |
| 車 | 濡れた路面のタイヤ音。ドップラー効果 f'=f·c/(c−v_r)、距離減衰と空気吸収 |
| 雨だれ | 窓の外に落ちたしずくが立てる「ポチャン」という音と、大きな気泡の共鳴音 |

## 性能
フレーム時間を監視し、重いときは雨滴などの描画数を減らします。それでも足りない場合は描画解像度を下げ、余裕が戻ったら元に戻します。
描画する雨滴の数には上限があります。雨量に応じた増え方と、粒の大きさの割合は、上の分布に従います。

## iPhoneでの使い方
1. GitHub Pages などで公開する（Settings → Pages → ブランチを選択）
2. iPhone の Safari で URL を開く
3. 共有 → 「ホーム画面に追加」で、アプリのように全画面で使えます

- 傾きセンサーは HTTPS で配信したときだけ使えます
- マナーモード（消音スイッチ）がオンだと、音が出ないことがあります。ヘッドホンを使うと、立体的な音の定位がよくわかります
