# ☔ Rain Simulator

iPhone（Safari）で動く、物理モデルにもとづいた雨シミュレーターです。`index.html` 1ファイルだけで動き、外部ライブラリも音声ファイルも使っていません。

## 操作
- **タップ**：落雷（距離と、雷鳴が届くまでの秒数を表示）
- **左右スワイプ**：風速を変更
- **設定**：雨量（mm/h）・風速（m/s）・音量、窓ガラス表示のオン/オフ、傾き
- **傾き**：加速度センサーで本当の重力方向を取得します。景色の雨は現実の「下」に向かって降り、窓の水滴も重力方向へ流れます（iPhoneを机に平らに置くと水滴は止まります）

## 物理モデル
| 現象 | モデル |
|---|---|
| 雨滴の大きさ | Marshall–Palmer 分布 N(D)=N₀e^(−ΛD), Λ=4.1R^−0.21 |
| 落下速度 | 終端速度 v(D)=9.65−10.3e^(−0.6D) m/s（Atlas ほか, 1973） |
| 風 | 抗力による緩和（時定数 τ=v/g）＋突風 |
| 雨筋の見え方 | 3D透視投影、露光時間ぶんのモーションブラー、被写界深度（窓にピントを合わせると外の景色と雨がボケる） |
| 地面 | 王冠状の水しぶき（放物運動する飛沫）、約0.23 m/sで広がる波紋 |
| 窓の水滴 | 体積を保存して合体する。重力(∝a³)が接触線のピン止め力(∝a)を上回ると流れ始める。濡れた跡は抵抗が下がり、後から来る水滴が同じ道を通る。流れた跡に小さな粒が残る |
| 水滴の見え方 | 球レンズとして、背景を上下反転・縮小して映す |
| 雨の音 | 水たまりに落ちた雨粒が閉じ込めた気泡の Minnaert 共鳴（f≈3.26/a）の「ポツッ」という音 |
| 雷 | 距離÷音速(343 m/s)だけ遅れて雷鳴。遠いほど高音が減衰し、ゴロゴロと長く響く |
| 視程 | 雨量が多いほど景色がかすむ |

※ 描画する雨滴の数は性能のため上限を設けていますが、雨量に応じた増え方と粒径の割合は上の分布に従います。

## iPhoneでの使い方
1. GitHub Pages などで公開する（Settings → Pages → ブランチを選択）
2. iPhone の Safari で URL を開く
3. 共有 → 「ホーム画面に追加」で、アプリのように全画面で使えます

- 傾きセンサーは HTTPS で配信したときだけ使えます
- マナーモード（消音スイッチ）がオンだと、音が出ないことがあります
